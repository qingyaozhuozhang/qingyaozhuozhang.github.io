    C++ 核心基础语法：从 C 语言到工程化开发

    原文件内容与 编程/C/核心基础语法.md 相同，主要是 C 语言知识。此处按原先“基础语法 → 数据类型 → 函数 → 数组和指针 → 结构体 → 文件”的学习方向重构为真正的 C++ 教程，C 的原始知识点仍保留在 C 目录。下面使用 C++17，编译示例默认 g++ -std=c++17 -Wall -Wextra -pedantic。

    1. C++ 的编译、运行与工具链

    一个 C++ 程序的基本过程：源码 .cpp → 预处理 → 编译/汇编 → 链接 → 可执行文件。C++ 与 C 不仅语法不同，还涉及对象生命周期、异常、模板和标准库等抽象。

    #include <iostream>

int main() {
    std::cout << "Hello C++17" << '\n';
    return 0;
}

    g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o app
./app
    • #include <iostream>：在预处理阶段引入标准输入/输出声明。
    • std::cout：输出流对象；<< 是流插入运算符。
    • int main()：程序入口函数；返回 0 表示成功。
    • -Wall -Wextra：启用常见警告；警告不等于错误，但建议逐个处理。

    2. 变量、类型与 const

    #include <iostream>
#include <string>

int main() {
    int count = 3;
    double distance_m = 2.75;
    bool ready = true;
    const int maximum = 10;
    auto ratio = distance_m / count;  // 推导为 double
    std::string name = "robot";
    std::cout << name << ": " << ratio << '\n';
}
    概念 示例 关键点
    值类型 int n = 3; 自身持有数据
    常量对象 const int n = 3; 初始化后不可修改
    类型推导 auto x = 2.5; 基于初始化表达式推导类型
    字符串 std::string text; 自动管理字符串内存
    空指针 nullptr 有明确的指针空值类型

    注意：auto 不是动态类型，只是编译期推导，变量仍具有固定类型。const 与引用/指针结合时，要看限定的是对象还是指针本身。

    3. 分支、循环与函数

    #include <iostream>
#include <vector>

int sum_positive(const std::vector<int>& values) {
    int sum = 0;
    for (int x : values) {
        if (x > 0) {
            sum += x;
        }
    }
    return sum;
}

int main() {
    std::vector<int> data{1, -3, 5};
    std::cout << sum_positive(data) << '\n';  // 6
}

    const std::vector<int>& 表示常量左值引用：函数不复制整个容器，也不允许通过该引用更改元素。范围 for 对容器元素迭代；如果希望修改元素，应使用 for (auto& x : values)，而不是 for (auto x : values)（后者复制元素）。

    4. 引用、指针与对象生命周期

    #include <iostream>

void add_one(int& n) { ++n; }
void print_if_exists(const int* value) {
    if (value != nullptr) std::cout << *value << '\n';
}

int main() {
    int x = 10;
    int& ref = x;          // 引用必须绑定到对象
    int* ptr = &x;         // 指针可以重新赋值，也可能为空
    add_one(ref);
    print_if_exists(ptr);  // 11
}

    关键区别：引用可以看成另一个对象的别名；指针保存地址且需要检查空值。函数返回局部变量的引用/地址通常会悬空（dangling）；访问已销毁对象属于未定义行为。

    5. 数组、string、vector 与常见容器

    #include <algorithm>
#include <iostream>
#include <map>
#include <string>
#include <vector>

int main() {
    std::vector<int> numbers{4, 1, 3, 1};
    numbers.push_back(2);
    std::sort(numbers.begin(), numbers.end());
    std::map<std::string, int> counter;
    for (int n : numbers) counter[std::to_string(n)]++;
    for (const auto& [key, count] : counter)
        std::cout << key << " appears " << count << " times\n";
}
    • std::vector：连续内存的动态数组，随机访问平均 \(O(1)\)，尾部追加摊还 \(O(1)\)。
    • std::map：通常是平衡树，查找、插入、删除 \(O(\log n)\)；std::unordered_map 平均 \(O(1)\)，最坏可退化。
    • std::string：优先于自己维护 char* 缓冲区；与 C 接口交互时可用 c_str()，但要考虑对象生命周期。

    6. class、封装与构造函数

    #include <cmath>
#include <iostream>

class Pose2D {
public:
    Pose2D(double x, double y) : x_(x), y_(y) {}

    double distance_to(const Pose2D& other) const {
        return std::hypot(x_ - other.x_, y_ - other.y_);
    }

    void move_by(double dx, double dy) {
        x_ += dx;
        y_ += dy;
    }

private:
    double x_;
    double y_;
};

int main() {
    Pose2D a(0.0, 0.0);
    Pose2D b(3.0, 4.0);
    std::cout << a.distance_to(b) << '\n';  // 5
}
    • private 将内部状态封装，外部不能直接修改；public 是对外接口。
    • Pose2D(double, double) 是构造函数，成员初始化列表比“先默认构造再赋值”更直接。
    • 尾部的 const 表示此成员函数不会通过 this 修改对象的非 mutable 状态。
    • C++ struct 与 class 的主要语义差别之一是默认访问权限：struct 默认为 public，class 默认为 private。

    7. RAII：资源获取即初始化

    核心思想：文件、互斥锁、堆内存等资源由对象拥有，离开作用域时析构自动释放。避免“每个函数手动记得 free/delete”的脆弱做法。

    #include <fstream>
#include <stdexcept>
#include <string>

void write_log(const std::string& path) {
    std::ofstream out(path, std::ios::app);
    if (!out) throw std::runtime_error("无法打开日志文件");
    out << "robot started\n";
} // 离开作用域时，ofstream 析构关闭文件

    #include <memory>
#include <string>

struct Node {
    std::string name;
    explicit Node(std::string value) : name(std::move(value)) {}
};

int main() {
    auto node = std::make_unique<Node>("base_link");
    // 不需要手动 delete
}

    std::unique_ptr 表示独占所有权；std::shared_ptr 维护共享所有权但可能形成循环引用，需要考虑 std::weak_ptr。优先使用直接对象和标准容器，确实需要动态所有权才使用智能指针。

    8. 拷贝、移动、左值与右值

    #include <iostream>
#include <string>
#include <utility>

int main() {
    std::string a = "pointcloud";
    std::string b = a;            // 拷贝：a 仍可正常使用
    std::string c = std::move(b); // 允许移动 b 的资源
    std::cout << a << ' ' << c << '\n';
}

    std::move 本身不搬运数据，只把表达式转换为可以用于移动构造/移动赋值的值类别；被移动的 b 仍是有效对象，但其内容不应依赖。理解 Rule of Zero：能交给标准库管理资源时，不要自行实现复杂的析构、拷贝和移动逻辑。

    9. 继承、多态与 override

    #include <iostream>
#include <memory>

class Planner {
public:
    virtual ~Planner() = default;
    virtual double plan_cost(double distance) const = 0;
};

class DistancePlanner : public Planner {
public:
    double plan_cost(double distance) const override { return distance; }
};

int main() {
    std::unique_ptr<Planner> planner = std::make_unique<DistancePlanner>();
    std::cout << planner->plan_cost(3.0) << '\n';
}

    virtual 允许基类接口经由派生类对象运行时动态派发；纯虚函数 = 0 使基类成为抽象类；override 会在编译期验证确实覆盖了某个虚函数。Nav2 的 GlobalPlanner::createPlan() 正是这一类插件接口的例子。

    10. 模板、泛型与 STL 算法

    #include <algorithm>
#include <iostream>
#include <vector>

template <typename T>
T maximum(T a, T b) {
    return a < b ? b : a;
}

int main() {
    std::vector<int> scores{12, 8, 15};
    const auto count = std::count_if(
        scores.begin(), scores.end(), [](int n) { return n >= 10; });
    std::cout << maximum(3, 7) << ", " << count << '\n';
}

    模板通常在实例化位置需要可见的定义，因此模板的实现往往放在头文件中。lambda [](int n){...} 是匿名函数对象；方括号里可以指定捕获外部变量的方式。捕获引用时要留意生命周期，避免返回携带悬空引用的 lambda。

    11. 异常、错误处理与测试

    #include <iostream>
#include <stdexcept>

int safe_divide(int a, int b) {
    if (b == 0) throw std::invalid_argument("除数不能为 0");
    return a / b; // 整数除法
}

int main() {
    try {
        std::cout << safe_divide(10, 2) << '\n';
        std::cout << safe_divide(10, 0) << '\n';
    } catch (const std::invalid_argument& e) {
        std::cerr << "参数错误: " << e.what() << '\n';
    }
}

    C++ 异常在 ROS 2 回调、线程边界与驱动边界应有明确的处理策略；不要用空 catch(...) 悄悄吞掉错误。基本测试不仅要覆盖正常输入，还要覆盖空容器、非法索引、溢出、文件不存在和资源释放。

    编译器检查

    g++ -std=c++17 -Wall -Wextra -Wconversion -pedantic \
    -fsanitize=address,undefined -fno-omit-frame-pointer main.cpp -o test_app
./test_app

    AddressSanitizer/UndefinedBehaviorSanitizer 可以发现许多常见的内存及未定义行为问题，但不能代替完整测试；构建时需要相应的运行库支持。

    12. 多线程与互斥锁

    #include <iostream>
#include <mutex>
#include <thread>

int main() {
    int counter = 0;
    std::mutex mutex;
    auto work = [&]() {
        for (int i = 0; i < 1000; ++i) {
            std::lock_guard<std::mutex> lock(mutex);
            ++counter;
        }
    };
    std::thread a(work), b(work);
    a.join();
    b.join();
    std::cout << counter << '\n'; // 2000
}

    std::lock_guard 在离开作用域时释放锁；若忘记锁，两个线程同时修改 counter 就会有数据竞争（未定义行为）。多线程对 I/O、ROS 回调延迟可能有帮助，不等于 CPU 密集型任务一定变快；还要考虑锁竞争与任务粒度。

    13. CMake 工程：头文件与实现文件的组织

    建议结构：

    robot_math/
├── CMakeLists.txt
├── include/robot_math/pose.hpp
├── src/pose.cpp
└── src/main.cpp

    cmake_minimum_required(VERSION 3.16)
project(robot_math LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
add_library(robot_math src/pose.cpp)
target_include_directories(robot_math PUBLIC include)
add_executable(robot_demo src/main.cpp)
target_link_libraries(robot_demo PRIVATE robot_math)

    cmake -S . -B build
cmake --build build -j
./build/robot_demo

    示例仅展示构建关系，运行前需创建对应 .hpp 和 .cpp 实现。ROS 2 的 ament_cmake 在 CMake 的基础上再处理包发现、依赖导出和安装等机制。

    14. C++ 在 Nav2 中怎么落地？

    1. 接口设计：nav2_core::GlobalPlanner 定义规划器应提供的方法；具体 NavFn/Smac 插件实现它。
    2. 对象生命周期：规划插件在 configure() 初始化所需的成本地图与 TF 句柄，在 cleanup() 回收资源。
    3. 引用传参：const geometry_msgs::msg::PoseStamped & start 避免复制位姿消息，表示不通过该引用修改输入。
    4. 返回值类型：nav_msgs::msg::Path 包含 header 与多组 PoseStamped，其坐标系必须与调用方约定一致。
    // 这是方法声明片段，不是可单独编译的完整程序
nav_msgs::msg::Path createPlan(
    const geometry_msgs::msg::PoseStamped & start,
    const geometry_msgs::msg::PoseStamped & goal
) override;

    需要结合 导航算法工程 中的代价地图、A* 搜索与 Nav2 源码一起理解，不要仅停留在会写 class 的层面。

    15. 巩固练习

    • 为 Pose2D 添加 yaw，并实现二维世界坐标到车体系的旋转：\(x'=\cos\theta\,dx+\sin\theta\,dy\)，\(y'=-\sin\theta\,dx+\cos\theta\,dy\)。
    • 用 std::priority_queue 编写四邻域 Dijkstra，再实现 A*；比较扩展节点数量。
    • 用 std::vector 保存路径点，对连续共线段进行简化；注意碰撞检测。
    • 用 CMake 将 .hpp、.cpp、测试程序独立组织，并使用编译警告和 Sanitizer 检查。
