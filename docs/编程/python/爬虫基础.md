# Python 数据采集：从 HTTP 到结构化记录

> 将原笔记的 Requests、正则、XPath、BS4、Selenium、并发与 Excel 章节合并为完整流程。采集活动应遵守网站条款、robots 规则、授权和适用法律；不要把绕过访问控制或规避限速当作通用技能。

## 1. 一次采集任务有哪些阶段？

```mermaid
flowchart LR
    A[明确数据来源与许可] --> B[HTTP 请求]
    B --> C[检测状态码/编码]
    C --> D[HTML/JSON 解析]
    D --> E[字段校验与去重]
    E --> F[CSV / 数据库]
    F --> G[日志与质量检查]
```

**爬虫 ≠ 搜索引擎**。工程项目通常是面向特定、获准访问的数据源做采集，不必从“模拟浏览器欺骗网站”开始。

## 2. HTTP 与 Requests

- `GET` 读取资源；`POST` 常用于提交表单或创建资源。具体是否可重试要看接口幂等性。
- 请求包含 URL、方法、headers、body；响应包含状态码、headers、body。
- HTTPS 在 HTTP 之上通过 TLS 提供传输加密与身份验证，不能简单理解为另一个独立应用协议。

```python
import requests

url = 'https://httpbin.org/json'   # 示例公共测试地址；离线时改用本地服务
try:
    r = requests.get(url, timeout=(3, 10))
    r.raise_for_status()
    data = r.json()
    print(type(data), list(data))
except (requests.RequestException, ValueError) as exc:
    print('请求或 JSON 解析失败:', exc)
```

`timeout=(连接超时, 读取超时)` 更清晰；`status_code == 200` 也不保证响应内容就是预期 JSON。

## 3. HTML、CSS 选择器、XPath 和正则如何选？

| 工具 | 适用对象 | 不适合 |
| --- | --- | --- |
| BeautifulSoup | 不规则 HTML 和简单选择器 | 对特别大的网页高频解析可能较慢 |
| lxml + XPath | 复杂 DOM 路径提取 | 非结构化自由文本 |
| JSON parser | 官方 JSON / API 返回 | HTML 页面 |
| 正则 `re` | 规则明确的短文本模式 | 用来解析任意复杂 HTML 结构 |

### 3.1 无外网也能运行的解析练习

```python
from bs4 import BeautifulSoup

html = '''<ul>
<li class="item" data-id="1">激光雷达</li>
<li class="item" data-id="2">IMU</li>
</ul>'''
soup = BeautifulSoup(html, 'html.parser')
for li in soup.select('li.item'):
    print(li.get('data-id'), li.get_text(strip=True))
```

同一个示例的 XPath：

```python
from lxml import etree
root = etree.HTML(html)
print(root.xpath('//li[@class="item"]/@data-id'))
```

## 4. 数据结构化、分页和去重

网站数据通常不够干净，先统一字段、编码、缺失值和主键，再存储。

```python
import csv

rows = [
    {'id': '1', 'name': '  lidar '},
    {'id': '1', 'name': 'lidar'},
    {'id': '2', 'name': 'imu'},
]
unique = {}
for row in rows:
    key = row['id']
    unique[key] = {'id': key, 'name': row['name'].strip()}

with open('result.csv', 'w', newline='', encoding='utf-8-sig') as f:
    writer = csv.DictWriter(f, fieldnames=['id', 'name'])
    writer.writeheader()
    writer.writerows(unique.values())
```

对分页接口先明确终止条件：最后一页标志、空结果、最大页数上限；避免因接口异常导致无限循环。

## 5. 重试、超时与速率限制

```python
import time
import requests

def fetch_text(url, tries=3):
    for attempt in range(tries):
        try:
            r = requests.get(url, timeout=10)
            r.raise_for_status()
            return r.text
        except requests.RequestException:
            if attempt == tries - 1:
                raise
            time.sleep(min(2 ** attempt, 8))
```

- 对于可安全重试的读取请求，可使用指数退避、有限重试和少量随机抖动。
- 遇到 `429` 应尊重 `Retry-After`，不能靠无限代理或并发规避限速。
- 如果数据源明确禁止自动化访问，应改用官方 API 或申请授权。

## 6. Selenium：何时必须用浏览器？

对于需要真实 JS 执行、页面交互且获准自动化的网页，可用 Selenium。对于公开的 JSON API，通常不必启动浏览器。

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

options = webdriver.ChromeOptions()
options.add_argument('--headless=new')
driver = webdriver.Chrome(options=options)
try:
    driver.get('https://example.com')
    heading = WebDriverWait(driver, 10).until(
        EC.presence_of_element_located((By.CSS_SELECTOR, 'h1')))
    print(heading.text)
finally:
    driver.quit()
```

“显式等待”对某个条件设置超时，通常比固定 `sleep` 更可靠。示例需要本地安装兼容浏览器与 Selenium 环境。

## 7. 并发采集和数据存储

- 线程池适合适量 HTTP I/O 任务；**并发数量受网站许可、速率限制和本地资源制约**。
- `Queue` 用于线程或进程间的任务/结果流转，避免多个 worker 直接同时写同一个 CSV 文件。
- Excel 可用 `openpyxl`，但大数据持续采集更推荐 CSV、SQLite 或合适的数据库。

## 8. 可观察性与法律边界

保存采集日志：时间、目标 URL（必要时脱敏）、状态码、提取条目数、失败原因。不要默认收集个人隐私、认证后数据或未经许可的受保护内容。
